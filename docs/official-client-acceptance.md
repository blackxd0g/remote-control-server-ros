# PAR-01 — приёмка официального клиента

Дата: 2026-09-07. Статус: частично проверено локально; PAR-01 не завершена. ARM64 отложена. Публикации и production deployment запрещены.

## Версия и стенд

Официальный [RustDesk 1.4.9](https://github.com/rustdesk/rustdesk/releases/tag/1.4.9), Linux x86_64 deb; SHA256 сверена с digest release asset: `7244ba47c40e804172044bfbe659467c54ce46554c98e78c8c0406f1d612fda3`. Контракт исходников закреплён commit `6c578292e8ebbbec708b76986ba8c4bc7c509747`.

Отдельные локальные контейнеры API, HBBS, TLS proxy и GUI-клиента с собственным профилем и синтетическими данными. GUI доступен через noVNC на host loopback. API использует отдельную SQLite; production и установленный Windows-профиль не изменялись. HTTP клиента проверялся только внутри тестового Docker-стенда; это не приёмка внешнего HTTPS. TLS proxy использует тестовый CA без отключения проверки сертификатов. После явного разрешения подключён отдельный тестовый relay по WSS.

## Исправления протокола

- [Официальный login dialog](https://github.com/rustdesk/rustdesk/blob/6c578292e8ebbbec708b76986ba8c4bc7c509747/flutter/lib/common/widgets/login.dart) ожидает `type=email_check`, `tfa_type=tfa_check` и отправляет `type=email_code` с `tfaCode` и `secret`. API адаптирован; прежний `tfa_code` сохранён. Добавлено чтение `verificationCode` наряду с `verification_code`. Challenge остаётся одноразовым и ограниченным по сроку; неверный код не выдаёт токен.
- [Модель адресной книги](https://github.com/rustdesk/rustdesk/blob/6c578292e8ebbbec708b76986ba8c4bc7c509747/flutter/lib/models/ab_model.dart) запрашивает страницы по 100. API прежде возвращал весь список на каждой странице. Теперь применяются `current` и `pageSize` (1–1000), стабильная сортировка и общий `total` после фильтрации прав. Вызовы без обоих параметров сохраняют полный список. Это пагинация текущего состояния, не snapshot между изменениями книги.

3. Расширить матрицу ОС через отдельные профили без изменения рабочего Windows-клиента.

Стенд содержит контейнеры с префиксом `rds-par01-`; остановка сохраняет их данные. Результаты каждого продолжения добавлять в журнал и эту матрицу.
