# Remote Control Server 2.0.1 — первый стабильный релиз

Представляю Remote Control Server 2.0.1 — независимую self-hosted платформу удалённого управления, совместимую с протоколом клиента RustDesk и оптимизированную для контейнеров MikroTik CHR / RouterOS на linux/amd64.

В одном лёгком образе доступны сервер идентификации, relay, API и современная web-консоль. Проект создаётся с упором на безопасность, контроль соединений до их установления и работу на устройствах с ограниченными ресурсами.

## Что уже реализовано

- обязательная авторизация клиента перед удалённым подключением;
- серверные сессии, JWT, logout, revoke и принудительный повторный вход;
- пользователи, роли, группы, устройства и адресные книги;
- ACL и централизованные стратегии;
- аудит входов, подключений и операций передачи файлов;
- TOTP, generic OIDC и LDAP / Active Directory;
- несколько relay-серверов, мониторинг и диагностика;
- webhooks, уведомления, резервное копирование и автоматизация;
- профили управляемых клиентов и API очереди для отдельного builder-worker;
- адаптивная web-консоль, тёмная и светлая темы, локализация и собственный брендинг;
- сценарии установки и обновления контейнера на RouterOS.

## Развёртывание

Docker-образ: `blackxdog/remote-control-server-ros:latest`

Поддерживаются all-in-one и раздельная схемы развёртывания. Данные и секреты сохраняются в `/data`; для production рекомендуется HTTPS через reverse proxy.

## Поддержать разработку

Поддержка на Boosty помогает уделять больше времени совместимости с актуальными клиентами, тестированию RouterOS и развитию функций уровня Server Pro.

Спасибо всем, кто тестирует проект, сообщает об ошибках и помогает ему развиваться.

> Remote Control Server — независимый проект и не связан с RustDesk. RustDesk является товарным знаком соответствующего правообладателя; название используется исключительно для описания протокольной совместимости.
