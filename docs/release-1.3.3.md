# RustDesk Server RouterOS 1.3.3

Release 1.3.3 starts the Live Connection Operations milestone.

- Adds an administration connection center built from official-client start, update, and close telemetry.
- Resolves the authenticated operator behind controller-device audit events.
- Shows active, stale, and recently closed connections with source device, target RustDesk ID, IP, type, timestamps, and duration.
- Adds a movable and hideable active-connections dashboard widget.
- Correlates out-of-order connection events chronologically.
- Removes the redundant core-services card from the sidebar.
- Sources every visible console version from the root `VERSION` file and updates the footer attribution.
