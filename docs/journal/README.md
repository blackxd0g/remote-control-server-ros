# Журнал разработки

Один файл на календарный день `YYYY-MM-DD.md` (Europe/Moscow), раздел на значимый блок работ. Новые разделы добавлять в конец. Ошибки исправлять датированным уточнением, сохраняя исходную историю.

Шаблон:

```markdown
## ID цели — название блока

- Запрос и план: ожидаемый результат.
- Изменения: существенные действия и ссылки на файлы.
- Проверки: действительно выполненные проверки; passed / failed / не выполнено и причина.
- Результат: достигнутое, ограничения; публикация/установка если разрешены и выполнены.
- Дальше: оставшаяся работа или отсутствие продолжения.
```

Не включать секреты, персональные данные, приватные адреса, дампы и каждую команду чтения. При сбое записывать краткое безопасное описание и влияние. Не приписывать старым проверкам текущую дату выполнения.
